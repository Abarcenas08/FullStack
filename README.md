# DevJobs — proyecto de aprendizaje full stack

Proyecto introductorio para practicar HTML, CSS y JavaScript mediante una página web de empleos.

## Contenido

- `index.html`: página principal de DevJobs.
- `empleos.html`: listado y filtros de empleos.
- `styles.css`: estilos y diseño adaptable.
- `script.js`: interacciones iniciales con los botones para postularse.
- `background.webp`: imagen usada en la página de inicio.

## Cómo verlo

Abre `index.html` en tu navegador. Para seguir practicando, puedes servir la carpeta con la extensión Live Server de Visual Studio Code.

## Tecnologías

HTML · CSS · JavaScript

> Proyecto en desarrollo. El objetivo es aprender y ampliar sus funciones paso a paso.
